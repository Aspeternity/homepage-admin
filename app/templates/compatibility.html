官方说明 ↗
Compose environment

    
Homepage 官方当前通过环境变量配置认证。Homepage Admin 只生成示例，不会为此请求 Docker 写权限。

  


  

    
Homepage MCP Compose 生成器
MCP 默认关闭、默认只读；Token 能读取 Homepage 配置中的服务凭据，请视为高敏感 Secret。
官方说明 ↗

    
    
Compose environment

    
不要把 MCP Endpoint 或 Token 暴露到不可信网络。 非浏览器 MCP 客户端通常需要 HOMEPAGE_MCP_TOKEN，Token 至少 32 个字符。
