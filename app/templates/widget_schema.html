工作方式

v0.3.2 不再依赖人工维护 15 个专属表单。同步器读取官方 docs/widgets/services/*.md 的 YAML 示例、Allowed fields，并读取 src/widgets/widgets.js 注册表。

Homepage 官方仓库→Schema Parser→/data 缓存→动态增强表单

Portainer、Proxmox、Jellyfin 等已有深度连接测试的类型，会在自动字段上继续叠加 Admin 的专门增强规则；其他官方 Widget 也会获得自动表单与基础测试。

手动操作

正常情况下无需操作。若 Homepage 刚新增 Widget，可立即同步，不必等待下一个自动检查周期。

离线导入 Widget Schema JSON

用于无法访问 GitHub 的环境。可粘贴另一个 Homepage Admin 导出的缓存对象，或直接粘贴 Widget 映射；导入后会写入 /data/widget-schema-cache.json。
